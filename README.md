# ❤️ Heart Disease Prediction

## 📌 Project Overview
This project focuses on predicting the presence of heart disease using Machine Learning classification techniques. The objective is to identify patients at higher risk of heart disease based on medical and demographic attributes.

The project includes Exploratory Data Analysis (EDA), data quality assessment, feature preprocessing, model tuning, and evaluation to develop a robust heart disease prediction workflow.

**Note:** This project supports decision-making research and is not a clinical diagnosis tool.

## 🎯 Business Objective
The main goal is to identify individuals at higher risk of heart disease at an early stage, supporting risk assessment and informed healthcare decision-making.

## 📂 Datasets
The project uses the following datasets :

- `values.csv` – Contains patient features and medical attributes used for prediction.
- `labels.csv` – Contains the target variable `heart_disease_present`, indicating whether heart disease is present.
